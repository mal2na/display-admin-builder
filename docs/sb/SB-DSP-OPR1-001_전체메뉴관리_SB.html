번호Description
개요 개요 수정 채널 탐색 구조(1~3 Depth)의 전체 메뉴를 조회하고, 선택 메뉴의 사용 여부 · 전시 순서 · 연결 대상 · 노출 조건 · 운영·소유 정보를 편집한다.
  • 이 화면은 메뉴를 생성·삭제하지 않는다. 신규 노출은 Container를 신규 생성하거나 기존 Container를 연결한 뒤 사용 여부를 켜는 방식
  • Depth·상위 메뉴는 채널 구조 기준값으로 조회만 한다. 어드민이 조정하는 것은 동일 상위 내 정렬 순서
  • 범위는 전체 메뉴. 탭메뉴는 Container·Template 안에서, 퀵메뉴는 별도 화면에서 관리
  • 승인 완료 전에는 채널에 반영되지 않고, 미승인 변경은 미리보기에서만 확인
