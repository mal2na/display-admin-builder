#한계보완 방향근거
L1"+ 메뉴 등록" 버튼이 정책과 충돌 정책상 전시 어드민에는 별도 메뉴 생성·삭제 기능이 없다. Container를 신규 생성하거나 기존 Container를 연결한 뒤 사용 여부를 켜는 방식이다. 버튼명을 "메뉴 노출 등록(Container 연결)"로 바꾸고, 신규 등록 사이드 패널의 첫 단계를 Container 선택으로 두어야 한다. PI-DSP-MNU-001
L2"메뉴 순서 수정"에 Depth 이동 금지 규칙이 없음 전체 메뉴의 Depth·상위 메뉴는 채널 구조 기준값으로 조회만 가능하다. Drag&Drop은 동일 상위 내 형제 순서 변경만 허용하고, Depth 간 이동은 드롭 불가로 차단해야 한다. 저장·취소, 변경 사유 입력도 미정의. PI-DSP-MNU-001
L31-3 옵션 조건의 라벨과 값이 뒤바뀜 "운영채널 선택 = 전체 노출 / 로그인 시 노출"은 로그인 조건이고, "로그인 조건 = PC / APP"은 채널 조건이다. 라벨을 교정하고, 정책 필수값인 권한 조건·대상 고객군 필터를 추가해야 한다. PI-DSP-MNU-001
L4필수/옵션 정의 모순 조회 조건에 필수 표시(*)가 있으나 설명은 "미 설정 시 전체 조회"다. 검색어 없이도 조회가 되는 구조이므로 필수 표시를 제거하거나, 필수 항목을 명확히 한정해야 한다. 기본값 "접힘"과 화면의 펼친 상태도 불일치. —
L5목록에 판단 정보가 없음 메뉴명과 미사용 배지만 있어 승인상태·연결 대상·담당 조직·담당자·최근 변경일시를 필터로 걸러도 목록에서 확인할 수 없다. 정책 필수값(사용 여부, 공개 상태, 담당 조직, 담당자, 변경 사유)을 트리 행 또는 요약 컬럼으로 노출해야 한다. PI-DSP-MNU-001
L6우측 상세·편집 영역이 스펙에서 빠짐 개요는 "사용 여부·전시 순서·연결 대상·노출 조건을 편집한다"고 했으나 화면에는 안내 문구만 있고 상세 패널에 번호가 없다. 상세 조회/편집 영역, 저장·취소, 변경 사유 입력, 미저장 이탈 방지를 별도 SB로 정의해야 한다. FN-DSP-MNU-001
L7"업데이트" 버튼이 두 행위를 섞음 "승인 완료 변경의 FO 즉시 반영"과 "재검수 요청"은 상태 전이가 다르다(ST-DSP-004→006 vs 001→002). 버튼을 검수 요청과 게시(반영)로 분리하고, 예약 게시(ST-DSP-005)도 함께 정의해야 한다. ST-DSP-001~006, PI-DSP-WFL-001
L8차단 케이스가 정의되지 않음 연결값 없음·미승인 연결은 게시 차단, 표시명·연결대상·권한·채널 불일치는 검수 요청 차단이다. 어떤 조건에서 버튼이 비활성되고 어떤 메시지가 나오는지 SB에 없다. PI-DSP-MNU-002
L9미사용 전환 시 영향도 확인 단계가 없음 연결된 Container·배너·CTA·퀵메뉴 사용처가 있으면 영향 범위를 먼저 확인해야 한다. 미사용 전환 전 영향도 팝업(사용처 목록·롤백 대상)이 필요하다. 화면의 1Depth_04(미사용) 하위 Depth가 그대로 보이는 것도 상속 규칙 미정의 문제. PI-DSP-MNU-001, PI-DSP-MNU-002
L10변경 사유·감사 로그 입력 UI가 없음 업데이트 확인 팝업에 변경 사유 입력 필드가 없다. 감사 로그 필수값(변경자·일시·대상·이전값·이후값·사유·승인자·결과)을 채울 입력 지점을 팝업 또는 상세 편집에 두어야 한다. PI-DSP-AUD-002
L11미리보기가 한 줄로만 정의됨 "새 창 호출"만 있고 무엇을 미리보는지(승인본/작업본), 조건별 렌더, 버전 비교, 판정 사유, 링크 유효성, 권한이 없다. → 본 문서 SB-DSP-OPR1-001-PV1로 분리 정의. PI-DSP-MNU-003, FN-DSP-MNU-001-4
L12공통 상태 케이스 누락 조회 결과 없음(Empty), 로딩, 조회 실패, 대량 데이터(3Depth 초과·페이징/가상 스크롤), 동시 편집 충돌, 역할별 버튼 노출(운영자/검수자/승인자) 규칙이 없다. PG-DSP-AUD-001
※ [확인필요] 미리보기 링크 외부 공유 허용 여부·유효시간, 비교 보기의 버전 보관 기준(최근 N개), 미리보기 조건 세트 저장(프리셋) 여부는 정책서에 근거가 없어 별도 확인이 필요하다.
